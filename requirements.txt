# Deep Research Agent 依赖清单

#     pip install -r requirements.txt
#
# 说明：这里不写死版本号，让 pip 自动安装彼此兼容的最新版，

# --- 步骤 1：配置管理 ---
# pydantic-settings：读取 .env 文件，把环境变量映射成配置类字段
# python-dotenv：底层负责解析 .env 文件
pydantic
pydantic-settings
python-dotenv

# --- 步骤 2：LLM 调用与重试 ---
# langchain：统一的 LLM 应用开发框架（Prompt、ChatModel、结构化输出等）
# langchain-openai：OpenAI 兼容接口的封装（DeepSeek/通义等也走这个）
# tenacity：给函数加"失败自动重试"的库
# json-repair：修复 LLM 偶尔生成的不合规 JSON（如中文内容里混入未转义引号）
langchain
langchain-openai
tenacity
json-repair

# --- 步骤 5：搜索与网页抓取 ---
# tavily-python：Tavily 搜索 API 的官方 SDK（专为 LLM Agent 设计，免费额度 1000 次/月）
# requests：发 HTTP 请求拿网页
# beautifulsoup4：解析 HTML，提取正文
tavily-python
requests
beautifulsoup4
